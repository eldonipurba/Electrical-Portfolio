# Implementasi Kran Air Otomatis Berbasis Arduino

## Deskripsi

Project ini merupakan implementasi sistem kran air otomatis menggunakan mikrokontroler Arduino. Sistem bekerja dengan mendeteksi keberadaan tangan atau objek menggunakan sensor, kemudian Arduino memproses sinyal tersebut untuk mengendalikan relay yang berfungsi sebagai saklar elektronik. Relay selanjutnya mengaktifkan solenoid valve sehingga aliran air dapat terbuka secara otomatis. Ketika objek tidak lagi terdeteksi, relay akan memutus arus ke solenoid valve sehingga aliran air berhenti.

Project ini dibuat sebagai media pembelajaran mengenai sistem kontrol otomatis, pemrograman Arduino, serta integrasi antara sensor, relay, dan aktuator.

---

## Tujuan Project

- Mempelajari dasar pemrograman Arduino.
- Memahami prinsip kerja sistem kontrol otomatis.
- Mengendalikan solenoid valve menggunakan relay.
- Mengintegrasikan sensor dengan Arduino sebagai sistem otomatis.
- Mendokumentasikan hasil perancangan sebagai portofolio pembelajaran.

## Cara Kerja Sistem

1. Sensor mendeteksi keberadaan tangan atau objek.
2. Arduino menerima sinyal dari sensor.
3. Arduino mengaktifkan relay.
4. Relay menyalurkan tegangan ke solenoid valve.
5. Solenoid valve terbuka sehingga air mengalir.
6. Ketika objek tidak lagi terdeteksi, relay mati dan solenoid valve menutup sehingga aliran air berhenti.

---

## Hasil Project

Project berhasil mensimulasikan sistem kran air otomatis yang mampu membuka dan menutup aliran air secara otomatis berdasarkan deteksi objek. Sistem ini menunjukkan penerapan dasar otomasi menggunakan Arduino, relay, dan solenoid valve.
